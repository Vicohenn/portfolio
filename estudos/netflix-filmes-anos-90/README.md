# Netflix — filmes de ação dos anos 90

Exercício guiado de análise exploratória com pandas.

**Contexto:** uma produtora especializada em filmes nostálgicos quer entender os filmes dos anos 1990 disponíveis na Netflix.

**O que foi feito:**
- Filtragem dos filmes lançados entre 1990 e 1999
- Cálculo da duração mais frequente (moda) dos filmes da década
- Contagem dos filmes de ação com menos de 90 minutos

**Ferramentas:** Python, pandas

**Arquivos:** [`notebook.ipynb`](notebook.ipynb) · dados em [`netflix_data.csv`](netflix_data.csv)
